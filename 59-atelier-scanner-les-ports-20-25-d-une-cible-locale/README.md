# Atelier : scanner les ports 20 à 25 d'une cible locale

**Rappel théorique** Un socket est un point d'extrémité de communication entre deux machines sur un réseau. En Python, le module `socket` permet d'établir des connexions TCP ou UDP vers une adresse IP et un port donné. Lorsqu'on tente une connexion TCP vers un port cible, trois résultats sont possibles : la connexion est acceptée (port ouvert), elle est refusée (port fermé) ou elle expire sans réponse (port filtré par un pare-feu). La méthode clé est `socket.connect_ex(('ip', port))` qui retourne `0` si la connexion réussit, ou un code d'erreur non nul sinon — ce qui en fait l'outil idéal pour un scanner de ports en Python. Erreurs fréquentes : oublier de fermer le socket après chaque tentative (ce qui consomme des ressources), ne pas définir de timeout (ce qui bloque le script indéfiniment sur un port filtré), ou confondre `connect()` (lève une exception) et `connect_ex()` (retourne un code). Il est aussi courant de scanner sans préciser l'adresse de la cible ou d'utiliser `localhost` sans vérifier que les services attendus y tournent réellement. Mini-exemple : ```python import socket s = socket.socket() s.settimeout(1) resultat = s.connect_ex(('127.0.0.1', 80)) if resultat == 0: print('Port 80 ouvert') else: print('Port 80 fermé ou filtré') s.close() ``` Ce rappel fait directement suite à l'introduction aux sockets vue dans le cours précédent.
