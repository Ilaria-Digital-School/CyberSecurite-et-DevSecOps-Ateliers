# Lire la table de routage d’une VM Linux

**Rappel théorique** Une table de routage est la carte de navigation d'un système réseau. Elle indique à la machine vers quel prochain saut (next hop) envoyer un paquet en fonction de l'adresse IP de destination. Chaque entrée comporte au minimum : une destination réseau (avec son masque en notation CIDR ou en masque décimal), une passerelle (gateway), une interface réseau associée, et une métrique (coût de la route). La route par défaut, notée 0.0.0.0/0, est celle utilisée quand aucune autre règle ne correspond — c'est la sortie vers Internet. Sur Linux, deux commandes exposent cette table : l'ancienne commande `route -n` et la commande moderne `ip route show` (ou `ip r`). L'erreur fréquente des débutants est de confondre la gateway (routeur prochain saut) avec l'adresse IP de destination finale. Une autre erreur classique est d'ignorer la colonne 'Flags' : le flag 'U' signifie que la route est active (Up), 'G' qu'elle utilise une passerelle externe, 'H' qu'elle pointe vers un hôte unique. Mini-exemple : si votre VM possède l'IP 192.168.1.10/24, vous verrez une route directe vers 192.168.1.0/24 via l'interface eth0 (sans passerelle, trafic local), et une route par défaut 0.0.0.0 via 192.168.1.1 (votre box/routeur) pour tout le reste du trafic. Ce modèle mental — local vs. gateway — est fondamental en cybersécurité pour comprendre les flux, détecter des routes suspectes ou analyser une compromission réseau. --- **Énoncé de l'atelier** Dans ce workshop, vous allez explorer et analyser la table de routage d'une VM Linux.
