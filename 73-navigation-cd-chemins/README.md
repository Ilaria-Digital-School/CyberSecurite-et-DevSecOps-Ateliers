# Navigation (cd, chemins)

**Rappel théorique** La navigation dans l'arborescence Linux repose sur deux concepts fondamentaux : les chemins absolus et les chemins relatifs. Un chemin absolu part toujours de la racine du système de fichiers, représentée par `/`. Par exemple, `/home/user/documents` désigne un emplacement précis, quel que soit votre répertoire courant. Un chemin relatif, lui, part de votre position actuelle dans l'arborescence. Si vous êtes dans `/home/user`, taper `cd documents` vous amène dans `/home/user/documents`. Quelques repères essentiels : `.` désigne le répertoire courant, `..` désigne le répertoire parent, `~` désigne le répertoire personnel de l'utilisateur connecté, et `-` (utilisé avec `cd`) vous ramène au répertoire précédent. La commande `cd` (change directory) est votre outil principal de déplacement. Erreurs fréquentes des débutants : confondre chemin absolu et relatif (oublier le `/` initial), oublier les majuscules (Linux est sensible à la casse), et supposer que `cd ..` depuis `/` fait quelque chose — il reste simplement à `/`. Mini-exemple : depuis `/home/user/`, `cd ../../etc` est équivalent à `cd /etc`.
