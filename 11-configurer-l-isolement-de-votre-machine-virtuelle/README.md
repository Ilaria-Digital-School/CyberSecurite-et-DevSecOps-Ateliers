# Configurer l'isolement de votre machine virtuelle

Rappel théorique sur l'isolement réseau Dans le contexte du laboratoire de cybersécurité, l'isolement désigne la configuration d'une machine virtuelle pour qu'elle fonctionne dans un réseau totalement privé et coupé des réseaux physiques. Ce concept est fondamental pour l'entraînement éthique car il contient les activités potentiellement risquées à l'intérieur d'un bac à sable sécurisé. L'isolement protège vos systèmes réels et empêche toute communication accidentelle avec l'internet extérieur ou votre réseau domestique. Deux erreurs fréquentes compromettent cet isolement. La première est de confondre les modes de réseau comme NAT ou réseau bridgé avec le réseau interne. Ces modes permettent une connexion à l'extérieur, ce qui va à l'encontre du but recherché. La seconde erreur est de négliger les autres canaux de communication comme les dossiers partagés, qui peuvent servir de vecteur de transfert de données si ils sont laissés actifs. Un modèle mental utile est de considérer la machine virtuelle isolée comme une pièce sans portes ni fenêtres à l'intérieur de votre ordinateur hôte. Prenons un mini-exemple chiffré. Dans une configuration correcte, si votre machine hôte a l'adresse IP 192.168.1.100 sur votre réseau domestique et que vous configurez un réseau interne virtuel nommé 'LABO_ISOLE', la machine virtuelle obtiendra une adresse dans un sous-réseau complètement différent, par exemple 192.168.99.10. Une commande ping de l'hôte vers cette adresse doit échouer complètement, démontrant l'absence de chemin réseau entre les deux mondes. L'isolement doit être hermétique.
