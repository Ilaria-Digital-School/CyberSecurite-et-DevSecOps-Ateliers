# Atelier : créer une liste de ports et la parcourir

**Rappel théorique** En Python, une liste est une structure de données ordonnée et mutable, capable de stocker plusieurs valeurs dans une seule variable. On la déclare avec des crochets : `ports = [80, 443, 22, 21]`. Pour parcourir une liste, on utilise principalement la boucle `for` : `for port in ports: print(port)`. Cette syntaxe lit chaque élément un par un, ce qui est fondamental en automatisation sécurité — notamment pour itérer sur une liste de ports à tester. Deux erreurs fréquentes à éviter : confondre `range()` (qui génère une séquence d'entiers) avec une vraie liste de ports métier, et oublier les deux-points `:` à la fin du `for`. On peut aussi construire une liste avec `list(range(1, 1025))` pour générer les 1024 premiers ports bien connus. Les dictionnaires, vus dans le dernier chapitre, peuvent enrichir ces listes en associant à chaque port un nom de service : `services = {80: 'HTTP', 443: 'HTTPS', 22: 'SSH'}`. Combiner listes et dictionnaires permet d'écrire des scripts de reconnaissance réseau lisibles et maintenables. Mini-exemple : ```python ports = [22, 80, 443] services = {22: 'SSH', 80: 'HTTP', 443: 'HTTPS'} for port in ports: print(f'Port {port} -> {services.get(port, "Inconnu")}') ``` --- **Énoncé de l'atelier** Dans cet atelier, vous allez construire un script Python autonome qui crée une liste de ports réseau représentatifs, la parcourt, et affiche des informations utiles sur chaque port. Ce travail pose les bases concrètes d'un scanner de ports, outil central en phase de reconnaissance lors d'un PenTest réseau ou applicatif. Votre script...
