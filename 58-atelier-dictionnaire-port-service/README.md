# Atelier : Dictionnaire port → service

**Rappel théorique** Un dictionnaire Python est une structure de données qui associe des clés à des valeurs, sur le modèle clé → valeur. Contrairement à une liste indexée par des entiers, un dictionnaire permet un accès direct à n'importe quelle valeur via sa clé, en temps constant. En cybersécurité, cette structure est omniprésente : on l'utilise pour mapper des numéros de ports à des noms de services, des adresses IP à des hostnames, des CVE à des descriptions, etc. Syntaxe de base : `mon_dict = {80: 'HTTP', 443: 'HTTPS', 22: 'SSH'}`. Pour accéder à une valeur : `mon_dict[80]` retourne `'HTTP'`. Pour éviter une erreur KeyError si la clé n'existe pas, on utilise la méthode `.get(clé, valeur_par_défaut)` : `mon_dict.get(9999, 'Inconnu')` retourne `'Inconnu'` sans lever d'exception. On peut itérer sur un dictionnaire avec `.items()` qui retourne des paires (clé, valeur). Erreurs fréquentes : accéder directement à une clé absente sans `.get()` (provoque un KeyError), confondre les types de clés (entier `80` vs chaîne `'80'`), ou oublier que les clés d'un dictionnaire sont uniques — une deuxième affectation sur la même clé écrase la précédente. Mini-exemple : `services = {21: 'FTP', 22: 'SSH', 80: 'HTTP'}` puis `print(services.get(22, 'Inconnu'))` affiche `SSH`. --- **Énoncé de l'atelier** Vous venez de travailler sur les listes de ports et leur parcours.
