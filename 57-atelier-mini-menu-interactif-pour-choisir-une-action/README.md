# Atelier : mini-menu interactif pour choisir une action

**Rappel théorique** Un menu interactif en ligne de commande repose sur trois piliers que vous avez déjà manipulés : la saisie utilisateur avec `input()`, les structures conditionnelles (`if / elif / else`) et les boucles (`while`). L'idée centrale est simple : on affiche des options, on lit le choix de l'utilisateur, on exécute l'action correspondante, puis on recommence jusqu'à ce que l'utilisateur choisisse de quitter. Ce pattern est fondamental en scripting de sécurité : la plupart des outils comme Metasploit ou des scanners maison exposent précisément ce type d'interface pour guider un opérateur. Erreurs fréquentes à éviter : ne pas valider l'entrée utilisateur (un utilisateur qui tape 'abc' quand on attend '1' peut faire planter le script) ; oublier la condition de sortie et créer une boucle infinie ; ne pas appeler les fonctions depuis le menu (réécrire le code au lieu de réutiliser des fonctions existantes). Mini-exemple mental : imaginez un distributeur automatique — il affiche un menu, attend votre choix, exécute l'action (rend la monnaie, distribue le produit) et revient au menu. Votre script doit se comporter exactement de la même façon. Une bonne pratique : encapsulez chaque action dans une fonction dédiée, et la logique du menu dans une fonction `main()`.
