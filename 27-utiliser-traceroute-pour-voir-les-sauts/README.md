# Utiliser traceroute pour voir les sauts

**Rappel théorique** Dans les activités précédentes, vous avez exploré la couche 3 du modèle OSI : la couche Réseau, responsable du routage des paquets IP d'une source vers une destination. Un paquet ne va jamais directement d'un ordinateur A à un ordinateur B sur Internet : il traverse une série de routeurs intermédiaires, appelés **sauts** (hops en anglais). Chaque routeur lit l'adresse IP de destination, consulte sa table de routage, et redirige le paquet vers le prochain saut. L'outil **traceroute** (ou `tracert` sous Windows) exploite ce mécanisme en jouant sur le champ **TTL (Time To Live)** de l'en-tête IP. Le TTL est un compteur décrémenté de 1 à chaque saut. Quand il atteint 0, le routeur détruit le paquet et renvoie un message ICMP 'Time Exceeded' à l'émetteur. Traceroute envoie successivement des paquets avec TTL=1, TTL=2, TTL=3, etc. : chaque routeur sur le chemin se 'dénonce' tour à tour en renvoyant ce message d'erreur. On obtient ainsi la liste ordonnée des routeurs traversés, avec les temps de réponse. Erreur fréquente : certains routeurs filtrent les messages ICMP ou refusent de répondre → ils apparaissent comme `* * *` dans la sortie. Cela ne signifie pas que le paquet ne passe pas, seulement que ce routeur est silencieux.
