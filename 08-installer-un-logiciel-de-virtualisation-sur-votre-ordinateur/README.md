# Installer un logiciel de virtualisation sur votre ordinateur

Rappel théorique fondamental La virtualisation consiste à exécuter plusieurs machines virtuelles sur un seul ordinateur physique. Chaque machine virtuelle fonctionne comme un ordinateur complet avec son propre système d'exploitation et ses applications. Ce concept est fondamental pour l'entraînement en cybersécurité, car il permet de créer un laboratoire isolé et sécurisé. Le modèle mental à adopter est celui de l'hyperviseur. Ce logiciel, aussi appelé système de virtualisation, se situe entre le matériel réel et les systèmes d'exploitation invités. Il alloue les ressources physiques comme le processeur, la mémoire et le stockage aux machines virtuelles. Il isole également ces machines entre elles et de l'hôte. Parmi les erreurs fréquentes des débutants, on trouve l'oubli de vérifier la compatibilité matérielle avant l'installation. Sans activation de la virtualisation dans le BIOS ou l'UEFI, la performance est extrêmement dégradée. Un autre écueil courant est le manque d'espace de stockage prévu pour les futures machines virtuelles. Un mini-exemple simple : si votre ordinateur a 16 Go de RAM et un processeur à quatre cœurs, vous pourriez allouer 2 Go de RAM et un cœur à une machine virtuelle Linux, et 4 Go de RAM et deux cœurs à une machine virtuelle Windows. Les deux fonctionneraient simultanément dans des fenêtres séparées, sur votre système d'exploitation principal. Préparer votre environnement hôte Avant de télécharger le moindre logiciel, votre première mission est d'auditer votre propre système.
