# Mini-projet ramp-up : documenter le chemin d’un paquet vers un site web

## Présentation du projet Ce mini-projet de consolidation clôture la section 'Fondamentaux des réseaux, protocoles et modèles OSI'. Vous avez acquis des bases solides sur les couches OSI 1 à 3, les trames Ethernet, les adresses MAC, les paquets IP et l'utilisation de traceroute. Il est maintenant temps de synthétiser tout cela dans un projet concret et documenté. **Votre mission** : choisir un site web public (par exemple `https://www.wikipedia.org`) et produire un rapport technique complet qui documente, étape par étape, le chemin qu'emprunte un paquet depuis votre machine jusqu'au serveur cible, en décrivant ce qui se passe à chaque couche OSI concernée. Ce projet simule une démarche de reconnaissance réseau préliminaire, compétence fondamentale pour tout futur spécialiste CyberSécurité & DevSecOps. --- ## Contexte professionnel Avant d'effectuer un PenTest ou d'analyser la surface d'attaque d'une application, un expert en cybersécurité doit comprendre précisément comment les données circulent sur le réseau : quels équipements sont traversés, quels protocoles sont utilisés, où se situent les points d'entrée potentiels. Cette capacité à lire et documenter un chemin réseau est un prérequis à l'utilisation d'outils comme Nmap, Wireshark ou Metasploit. --- ## Périmètre technique Le projet couvre obligatoirement : - La couche physique (câble, Wi-Fi, interface réseau) - La couche liaison de données (trame Ethernet, adresse MAC source/destination) - La couche réseau (adresse IP source/destination, routage, TTL) - Les sauts intermédiaires observés via traceroute - Une capture de trame commentée (Wireshark) - La résolution DNS comme mécanisme préalable à l'acheminement IP Le projet n'impose pas...
