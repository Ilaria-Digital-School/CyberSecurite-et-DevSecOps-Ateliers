# Empiler les couches (activité Lego virtuelle)

**Rappel théorique** Le modèle OSI (Open Systems Interconnection) est un cadre conceptuel qui découpe la communication réseau en 7 couches distinctes, chacune ayant un rôle précis. De bas en haut : Physique (1), Liaison de données (2), Réseau (3), Transport (4), Session (5), Présentation (6), Application (7). Chaque couche communique uniquement avec la couche immédiatement au-dessus ou en dessous d'elle, et encapsule les données reçues de la couche supérieure en y ajoutant son propre en-tête (header) — c'est le principe d'encapsulation. À l'émission, on descend les couches en empilant des enveloppes ; à la réception, on remonte en les dépilant. Le modèle TCP/IP, plus utilisé en pratique, regroupe ces 7 couches en 4 (Application, Transport, Internet, Accès réseau). Erreur fréquente : confondre la couche 3 (adressage IP, routage) avec la couche 2 (adressage MAC, switch). Un switch travaille en couche 2 ; un routeur travaille en couche 3. Autre erreur classique : croire que HTTP est une couche — c'est un protocole de la couche Application (7). Mini-exemple : quand vous envoyez un email, votre client mail (couche 7) génère le message, SMTP l'encapsule, TCP (couche 4) ajoute un segment, IP (couche 3) ajoute un paquet, Ethernet (couche 2) ajoute une trame, et le signal physique (couche 1) traverse le câble. Ce rappel vous sert de boussole pour tout l'atelier. **Énoncé de l'atelier** Dans cet atelier, vous allez matérialiser le processus d'encapsulation et de désencapsulation du modèle OSI à travers une activité de construction virtuelle inspirée des briques Lego.
