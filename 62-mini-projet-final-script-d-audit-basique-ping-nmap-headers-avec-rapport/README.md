# Mini-projet final : script d'audit basique (ping, nmap, headers) avec rapport

## Présentation du projet Ce mini-projet final clôture la section 'Bases de la programmation Python pour l'automatisation sécurité'. Il s'agit de concevoir et livrer un **script Python complet d'audit réseau et applicatif basique**, capable de : 1. **Vérifier la disponibilité d'une cible** via une séquence de ping (ICMP ou équivalent Python). 2. **Scanner les ports ouverts** d'une cible locale ou distante (périmètre autorisé) via un wrapper Nmap (exécution subprocess + parsing XML). 3. **Analyser les en-têtes HTTP** d'une URL cible avec la bibliothèque `requests` (détection de headers de sécurité manquants : X-Frame-Options, Content-Security-Policy, Strict-Transport-Security, X-Content-Type-Options, etc.). 4. **Générer un rapport structuré** regroupant les résultats des trois phases, disponible en formats texte (.txt), CSV et JSON. Le script doit respecter les **bonnes pratiques de scripting sécurisé** : shebang correct, gestion des droits, aucun secret en dur, gestion des erreurs robuste, logs horodatés. ## Contexte professionnel Dans un contexte de PenTest ou d'audit de sécurité, la phase de reconnaissance et d'audit initial est critique. Ce script simule un outil d'audit léger utilisable par un Spécialiste CyberSécurité pour obtenir une première cartographie d'une cible avant d'approfondir les investigations avec des outils spécialisés. ## Périmètre technique - **Langage** : Python 3.x - **Bibliothèques autorisées** : `subprocess`, `socket`, `requests`, `csv`, `json`, `datetime`, `argparse`, `os`, `sys`, `xml.etree.ElementTree` (ou `python-nmap`) - **Cible** : environnement local de type lab (machine virtuelle, conteneur Docker, réseau isolé) ou toute cible pour laquelle l'apprenant dispose d'une **autorisation explicite**. - **Rapport** : fichier texte lisible, fichier CSV et fichier JSON, tous horodatés.
