# Atelier : Conversions de types et opérations simples

**Rappel théorique** En Python, chaque valeur possède un type : entier (int), flottant (float), chaîne de caractères (str), booléen (bool). Lorsque vous récupérez des données depuis un fichier, une entrée utilisateur ou une réponse réseau, elles arrivent quasi systématiquement sous forme de chaînes de caractères. Pour les exploiter dans des calculs ou des comparaisons, vous devez les convertir explicitement. C'est ce qu'on appelle la conversion de types ou casting. Les fonctions de conversion principales sont : int(), float(), str(), bool(). Exemple : la saisie utilisateur input() renvoie toujours une str. Si l'utilisateur tape '8080', vous devez écrire int(input()) pour obtenir un entier utilisable dans un calcul. Erreurs fréquentes : tenter de convertir une chaîne non numérique en entier (int('abc') lève une ValueError), oublier qu'une division entre deux entiers renvoie un float en Python 3 (7 / 2 = 3.5), confondre == (comparaison) et = (affectation). Le modèle mental à retenir : imaginez un tuyau de données — avant de faire passer des données dans un calcul ou une condition, vérifiez que leur type est compatible, sinon convertissez-les. Un mini-exemple : port = '443' ; port_int = int(port) ; print(type(port_int), port_int * 2) affichera 886. --- **Énoncé de l'atelier** Vous travaillez sur un petit outil de reconnaissance réseau en Python.
