# Explorer l'environnement de votre machine virtuelle Linux

Rappel théorique : Du noyau à l'utilisateur Le système d'exploitation Linux est un chef d'orchestre logiciel. Son rôle essentiel est de gérer les ressources matérielles de l'ordinateur et de fournir une plateforme stable pour l'exécution des programmes. Le noyau, ou kernel, constitue le cœur de ce système. Il agit comme un intermédiaire direct entre le matériel physique et les logiciels. Le modèle mental à adopter est celui d'une superposition de couches. Au plus bas niveau, le matériel. Le noyau dialogue avec ce matériel via des pilotes. Il offre ensuite des services aux processus utilisateurs par le biais d'appels système. La couche shell et les utilitaires en espace utilisateur complètent l'interface, permettant à l'utilisateur de donner des ordres à la machine. Une erreur fréquente pour les débutants est de confondre le noyau avec le système d'exploitation dans son ensemble. Linux est strictement le noyau. La distribution, comme Ubuntu ou Debian, est l'emballage complet qui inclut le noyau, des utilitaires système, et un gestionnaire de paquets. Une autre erreur est de ne pas comprendre la distinction fondamentale entre l'espace noyau, réservé et protégé, et l'espace utilisateur, où vos applications s'exécutent. Prenons un mini-exemple chiffré. Lorsque vous lancez la commande `ls` pour lister des fichiers, le shell (dans l'espace utilisateur) interprète votre commande. Il crée un nouveau processus qui fait un appel système au noyau pour lire le contenu du répertoire.
