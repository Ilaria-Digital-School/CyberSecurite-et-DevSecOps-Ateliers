# Explorer avec tree

**Rappel théorique** Avant de démarrer cet atelier, revenons sur les concepts essentiels. La commande `tree` est un utilitaire Linux qui affiche la structure d'un répertoire sous forme d'arborescence visuelle, en montrant les dossiers et fichiers de manière hiérarchique. Contrairement à `ls` qui liste le contenu d'un seul niveau, `tree` permet de visualiser récursivement toute une arborescence en un seul coup d'œil — ce qui est extrêmement utile en cybersécurité pour cartographier rapidement la structure d'un système cible, identifier des fichiers suspects ou comprendre l'organisation d'une application web. Quelques options fondamentales : `tree -L 2` limite l'affichage à 2 niveaux de profondeur, `tree -a` inclut les fichiers cachés (ceux commençant par un point, souvent critiques en sécurité), `tree -d` affiche uniquement les répertoires, `tree -f` affiche les chemins complets, et `tree -o output.txt` redirige le résultat vers un fichier. Erreur fréquente : oublier que `tree` n'est pas toujours installé par défaut — il faut parfois l'installer via `apt install tree`. Autre piège : lancer `tree /` sans limiter la profondeur sur un système complet, ce qui génère des milliers de lignes. Mini-exemple : `tree -L 2 -a /var/www/html` affiche les deux premiers niveaux de l'arborescence d'un site web, fichiers cachés inclus — un réflexe de départ lors d'une phase de reconnaissance. --- **Énoncé de l'atelier** Bienvenue dans cet atelier pratique consacré à la commande `tree`.
