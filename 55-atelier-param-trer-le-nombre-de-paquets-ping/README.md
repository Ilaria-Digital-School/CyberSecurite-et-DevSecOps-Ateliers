# Atelier : Paramétrer le nombre de paquets ping

**Rappel théorique** Dans les ateliers précédents, vous avez découvert comment utiliser le module `subprocess` pour exécuter des commandes système depuis Python, et notamment lancer la commande `ping` pour tester la connectivité réseau. Revenons sur les points essentiels avant d'aller plus loin. Le module `subprocess` permet d'exécuter des processus externes en Python. La fonction `subprocess.run()` est la méthode recommandée pour lancer une commande, capturer sa sortie (`capture_output=True`), gérer les erreurs (`check=True`) et contrôler les paramètres passés à la commande. La commande `ping` envoie par défaut un nombre fixe de paquets ICMP (4 sur Windows, illimité sur Linux/macOS sans l'option `-c`). Pour contrôler ce nombre, on utilise l'option `-n` sur Windows et `-c` sur Linux/macOS. L'argument `sys.argv` permet de récupérer des paramètres passés en ligne de commande à votre script Python, ce qui rend vos scripts réutilisables et configurables sans modifier le code source. Erreur fréquente : oublier de convertir `sys.argv[1]` en entier (`int()`) avant de l'injecter dans la commande, ou ne pas gérer le cas où l'argument est absent ou invalide. Exemple minimal : `subprocess.run(['ping', '-c', '3', '8.8.8.8'])` envoie 3 paquets vers Google DNS sous Linux. Ce rappel posé, vous allez maintenant construire un script plus robuste et paramétrable, compétence clé pour tout spécialiste CyberSécurité qui automatise des tâches de reconnaissance réseau. --- **Énoncé de l'atelier** Vous allez améliorer le script de ping développé lors de l'atelier précédent ("Atelier : script qui exécute 'ping' et sauvegarde la sortie") en y ajoutant la possibilité de paramétrer dynamiquement le nombre de paquets envoyés...
