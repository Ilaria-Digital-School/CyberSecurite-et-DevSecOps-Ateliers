# Atelier : extraire toutes les adresses IP d'un log

**Rappel théorique** Les expressions régulières (regex) sont des séquences de caractères qui définissent un motif de recherche. En Python, le module `re` permet d'appliquer ces motifs sur des chaînes de texte pour rechercher, extraire ou remplacer des données. Une adresse IPv4 est composée de quatre octets séparés par des points, chaque octet étant un nombre entre 0 et 255. Le motif regex classique pour capturer une IP est : `\b(?:\d{1,3}\.){3}\d{1,3}\b`. Décortiquons-le : `\b` est une ancre de mot, `\d{1,3}` capture 1 à 3 chiffres, `\.` correspond à un point littéral, et la structure est répétée 3 fois avant le dernier octet. La fonction `re.findall()` renvoie une liste de toutes les correspondances trouvées dans une chaîne. Attention aux erreurs fréquentes : oublier d'échapper le point (`.` en regex signifie 'n'importe quel caractère', pas un point littéral), ou confondre `re.search()` (première occurrence) avec `re.findall()` (toutes les occurrences). Mini-exemple : `re.findall(r'\b(?:\d{1,3}\.){3}\d{1,3}\b', '192.168.1.1 attacked 10.0.0.5')` retourne `['192.168.1.1', '10.0.0.5']`. Ce rappel vous prépare directement à l'atelier qui suit. --- **Présentation de l'atelier** Dans ce workshop, vous allez écrire un script Python capable de lire un fichier de log, d'en extraire automatiquement toutes les adresses IPv4 présentes, et de produire un résultat exploitable. Cette compétence est fondamentale en cybersécurité : l'analyse de logs est l'une des premières tâches d'un analyste SOC, d'un pentesteur ou d'un ingénieur DevSecOps qui cherche à identifier des sources d'attaque, des hôtes suspects ou des comportements anormaux dans une infrastructure.
