# Trafic complet – de la requête HTTP à la réponse (diagramme annoté)

## Présentation du projet Ce mini-projet est la synthèse pratique des compétences acquises tout au long du chapitre 'Fondamentaux des réseaux, protocoles et modèles OSI'. Vous avez travaillé le subnetting, le routage, NAT, DNS, TCP/UDP et HTTP. Il s'agit maintenant de produire un diagramme annoté complet représentant le cycle de vie d'une requête HTTP, depuis la saisie d'une URL dans un navigateur jusqu'à la réception de la réponse du serveur web, en passant par toutes les couches OSI concernées. Ce travail est directement ancré dans le quotidien d'un spécialiste CyberSécurité : comprendre précisément ce qui transite sur le réseau est un prérequis absolu pour identifier des anomalies, détecter des attaques (MITM, DNS poisoning, injection HTTP, etc.) ou valider que des contrôles de sécurité sont bien en place. ## Contexte applicatif Vous simulez le rôle d'un analyste sécurité junior chargé d'onboarder de nouveaux membres dans l'équipe SOC/PenTest. Vous devez produire un support de référence technique interne illustrant le flux réseau complet d'une requête HTTP classique (non chiffrée, port 80) dans un environnement incluant : - Un client (navigateur) - Un résolveur DNS local - Un serveur DNS autoritaire - Une passerelle NAT - Un serveur web distant Ce support servira de base à l'analyse de captures Wireshark et à l'identification de points d'attaque potentiels. ## Périmètre technique à couvrir Le diagramme et les annotations doivent couvrir les phases suivantes : **Phase 1 – Résolution DNS** - Saisie de l'URL (ex : http://www.example.com/index.html) - Consultation du cache navigateur, puis du fichier /etc/hosts...
