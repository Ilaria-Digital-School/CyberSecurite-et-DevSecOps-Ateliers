# Lire une trame Ethernet capturée

**Rappel théorique** Une trame Ethernet est l'unité de transmission de la couche 2 (Liaison de données) du modèle OSI. Elle encapsule les données provenant des couches supérieures et les transporte d'une interface réseau à une autre sur un même réseau local. Une trame Ethernet standard (format IEEE 802.3) est composée des champs suivants : le Préambule (7 octets de synchronisation), le SFD – Start Frame Delimiter (1 octet), l'adresse MAC destination (6 octets), l'adresse MAC source (6 octets), le champ EtherType/Longueur (2 octets, indique le protocole encapsulé, ex. 0x0800 pour IPv4, 0x0806 pour ARP), le champ Data/Payload (46 à 1500 octets) et enfin le FCS – Frame Check Sequence (4 octets de contrôle d'intégrité CRC32). Erreurs fréquentes à éviter : confondre adresse MAC et adresse IP (la MAC est physique, gravée dans la carte réseau, tandis que l'IP est logique et configurée) ; oublier que le champ EtherType permet d'identifier le protocole de couche 3 encapsulé ; négliger le FCS qui garantit l'intégrité de la trame. Mini-exemple : si EtherType vaut 0x0800, la trame transporte un paquet IPv4. Si la destination MAC est FF:FF:FF:FF:FF:FF, il s'agit d'un broadcast envoyé à toutes les machines du réseau local.
