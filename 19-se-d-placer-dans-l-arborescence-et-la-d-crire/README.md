# Se déplacer dans l'arborescence et la décrire

Rappel théorique : Naviguer dans l'arborescence L'arborescence Linux est une structure de dossiers hiérarchisée. Elle part de la racine, notée '/', qui contient tous les autres dossiers, appelés répertoires. Chaque utilisateur dispose d'un dossier personnel, généralement '/home/nom_utilisateur'. Le chemin d'accès absolu décrit l'emplacement complet d'un fichier depuis la racine, tandis que le chemin relatif décrit la position par rapport au répertoire courant. Le modèle mental essentiel est de se représenter l'arborescence comme un arbre inversé, avec une seule racine et de nombreuses branches. Pour s'y déplacer, on utilise principalement la commande 'cd' (change directory), suivie soit d'un chemin absolu (commençant par '/'), soit d'un chemin relatif. Pour voir le contenu d'un répertoire, on utilise 'ls' (list). Pour connaître son emplacement exact, on utilise 'pwd' (print working directory). Une erreur fréquente est de confondre chemin absolu et chemin relatif, et de ne pas comprendre la signification des symboles spéciaux. Par exemple, '.' représente le répertoire courant, '..' le répertoire parent, et '~' le répertoire personnel. Ne pas les utiliser correctement peut entraîner des commandes exécutées au mauvais endroit. Mini-exemple : Depuis votre dossier personnel '~', tapez 'cd /usr/bin'. Vous êtes maintenant dans le dossier 'bin' du répertoire 'usr', près de la racine. Tapez ensuite 'cd ../local'. Vous montez d'un niveau dans 'usr' puis descendez dans 'local'. Enfin, tapez 'cd' sans argument pour revenir directement à votre dossier personnel.
