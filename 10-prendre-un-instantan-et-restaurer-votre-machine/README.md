# Prendre un instantané et restaurer votre machine

Rappel théorique et mise en contexte Un instantané, ou snapshot, est une capture de l'état complet d'une machine virtuelle à un instant T. Il comprend la mémoire vive, l'état du processeur, les disques durs virtuels et les fichiers de configuration. Dans votre laboratoire de cybersécurité, cet outil est fondamental car il permet de figer un état stable avant une manipulation risquée, comme l'installation d'un outil d'analyse ou le test d'une attaque. Le modèle mental à adopter est celui d'une ligne de temps. Votre machine virtuelle avance. Un instantané marque un point de sauvegarde sur cette ligne. Vous pouvez ensuite continuer à avancer, effectuer des modifications, et revenir en arrière au point marqué si nécessaire, comme si vous rembobiniez un film. Cette capacité à restaurer un système en quelques secondes est au cœur de la méthode d'entraînement sécurisé. Une erreur fréquente consiste à créer des instantanés de manière anarchique, sans nommage clair, ce qui conduit rapidement à une confusion totale dans la gestion des versions de votre machine. Une autre erreur est de croire qu'un instantané remplace une sauvegarde complète hors du logiciel de virtualisation. Ce n'est pas le cas : les fichiers d'instantané sont liés à votre installation locale et à votre logiciel hôte. Voici un mini-exemple chiffré : imaginez que vous prépariez une machine pour analyser un échantillon de logiciel malveillant. Vous commencez par un système Linux propre.
