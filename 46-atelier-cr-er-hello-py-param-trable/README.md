# Atelier : créer hello.py paramétrable

**Rappel théorique** Un script Python exécutable est un fichier .py que l'on peut lancer directement depuis un terminal avec la commande `python hello.py`. Pour rendre ce script dynamique, on utilise le module `sys` de la bibliothèque standard, et plus précisément `sys.argv`, qui est une liste contenant le nom du script en position 0, puis chaque argument passé en ligne de commande en positions 1, 2, etc. Par exemple, si vous exécutez `python hello.py Alice`, alors `sys.argv[0]` vaut `'hello.py'` et `sys.argv[1]` vaut `'Alice'`. Les erreurs les plus fréquentes chez les débutants sont : oublier de vérifier que l'argument existe avant d'y accéder (ce qui provoque une `IndexError`), confondre `sys.argv[1]` (une chaîne de caractères) avec un entier sans conversion explicite, et oublier le shebang `#!/usr/bin/env python3` pour rendre le script directement exécutable sur Linux/Mac. Mental model clé : pensez à `sys.argv` comme à un tableau de mots tapés dans le terminal, chaque mot étant accessible par son index. Mini-exemple : ```python import sys if len(sys.argv) > 1: print('Bonjour', sys.argv[1]) else: print('Bonjour, inconnu !') ``` Ce rappel pose les bases nécessaires pour aborder cet atelier en autonomie. --- **Énoncé de l'atelier** Dans cet atelier, vous allez créer un script Python nommé `hello.py` capable d'adapter son comportement en fonction des arguments fournis en ligne de commande. Ce type de script est fondamental dans un contexte de cybersécurité et DevSecOps : la quasi-totalité des outils d'automatisation (scanners, outils de reconnaissance, scripts de test) reçoivent leurs paramètres via la ligne de commande.
