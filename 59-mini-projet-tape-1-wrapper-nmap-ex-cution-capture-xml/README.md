# Mini-projet étape 1 : wrapper Nmap (exécution + capture XML)

## Présentation du projet Ce mini-projet constitue la première étape d'un wrapper Nmap en Python. L'objectif est de créer un script Python capable de lancer des scans Nmap de manière programmatique, de capturer la sortie au format XML, puis de parser et structurer les résultats dans des dictionnaires et listes Python exploitables. Ce projet s'appuie directement sur les compétences acquises lors des ateliers précédents : manipulation de listes et dictionnaires, expressions régulières, sockets, gestion des timestamps. Vous allez désormais combiner tout cela dans un outil de reconnaissance réseau réaliste, utilisé quotidiennement par les pentesters. ## Contexte professionnel Dans un contexte de PenTest applicatif, la phase de reconnaissance (recon) est critique. Nmap est l'outil de référence pour découvrir les ports ouverts, les services actifs et les versions logicielles d'une cible. Automatiser ces scans avec Python permet de : - Intégrer les résultats dans des pipelines d'analyse automatisée - Alimenter des rapports de vulnérabilités de manière structurée - Rejouer des scans à intervalles réguliers et comparer les résultats dans le temps ## Périmètre technique Le wrapper doit couvrir les fonctionnalités suivantes : ### 1. Exécution de Nmap via Python - Utilisation du module `subprocess` pour lancer Nmap avec les arguments souhaités - Paramétrage dynamique : cible (IP ou plage), ports à scanner, type de scan (-sV, -sS, -sT, etc.) - Gestion des erreurs d'exécution (cible inaccessible, Nmap non installé, permissions insuffisantes) ### 2. Capture de la sortie XML - Utilisation du flag `-oX` de Nmap pour générer la sortie au format XML...
