# Atelier : fonction est_pair(port)

**Rappel théorique** Une fonction en Python est un bloc de code réutilisable que l'on définit une fois et que l'on peut appeler autant de fois que nécessaire. On la déclare avec le mot-clé `def`, suivi du nom de la fonction, de ses paramètres entre parenthèses, et d'un bloc indenté contenant la logique. Le mot-clé `return` permet de renvoyer une valeur à l'appelant. Si `return` est absent, la fonction retourne implicitement `None`. Mental model : pensez à une fonction comme à une machine à traiter : on lui donne une entrée (paramètre), elle effectue un traitement, et elle sort un résultat (valeur de retour). La fonction ne sait rien du monde extérieur, seulement ce qu'on lui passe. Erreurs fréquentes chez les débutants : oublier le `return` et se demander pourquoi la fonction affiche `None` ; confondre `print()` et `return` (print affiche à l'écran, return transmet une valeur) ; mal indenter le corps de la fonction, ce qui provoque une `IndentationError`. Mini-exemple : ```python def est_positif(nombre): return nombre > 0 print(est_positif(5)) # True print(est_positif(-3)) # False ``` Ici, la fonction retourne un booléen (`True` ou `False`) selon la condition évaluée.
