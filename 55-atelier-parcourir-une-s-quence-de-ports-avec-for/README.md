# Atelier : parcourir une séquence de ports avec for

**Rappel théorique** La boucle `for` en Python est l'outil idéal pour itérer sur une séquence finie et connue à l'avance. Contrairement à `while` qui continue tant qu'une condition est vraie, `for` parcourt chaque élément d'un itérable (liste, plage de valeurs, chaîne…) et s'arrête automatiquement. La fonction `range(debut, fin, pas)` est votre alliée pour générer des séquences numériques : `range(1, 1025)` produit les entiers de 1 à 1024 inclus. Mental model : imaginez un agent de sécurité qui vérifie chaque porte d'un couloir numéroté — il commence à la porte 1, avance jusqu'à la dernière, sans jamais sauter ni rester bloqué. Erreurs fréquentes à éviter : oublier que `range(1, 1025)` exclut 1025 (la borne supérieure est toujours exclue) ; confondre l'index de boucle avec une valeur métier (ici, le numéro de port est directement utilisable) ; négliger l'indentation qui délimite le bloc d'instructions répétées. Mini-exemple : ```python for port in range(20, 26): print(f"Vérification du port {port}") ``` Ce snippet affiche les ports 20 à 25. On voit immédiatement comment combiner `for`, `range` et une f-string pour produire un affichage lisible.
