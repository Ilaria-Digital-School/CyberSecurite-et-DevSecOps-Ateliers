# Analyser trois cyberattaques connues avec ce vocabulaire

Rappel théorique : les concepts fondamentaux Cet atelier pratique vous permet d'appliquer le vocabulaire clé appris précédemment, un outil essentiel pour tout professionnel de la sécurité. Les termes 'menace', 'vulnérabilité' et 'risque' sont trop souvent confondus, ce qui nuit à la clarté des analyses techniques et des communications métier. Une 'menace' désigne tout événement ou acteur potentiel pouvant causer un préjudice à un système. Il s'agit de l'élément dangereux, comme un code malveillant ou un attaquant malveillant. La 'vulnérabilité' est une faiblesse ou une faille intrinsèque du système, qu'il s'agisse d'un défaut de code logiciel, d'une erreur de configuration ou d'une procédure organisationnelle inadéquate. Le 'risque' est le produit de la probabilité qu'une menace exploite une vulnérabilité, et de l'impact qui en résulte. Une erreur fréquente est de considérer une menace comme une conséquence alors que c'est une cause potentielle. Une autre confusion courante est d'évaluer un risque élevé uniquement sur la base d'une menace spectaculaire, sans tenir compte de la présence (ou de l'absence) d'une vulnérabilité exploitable correspondante dans le système ciblé. Prenons un mini-exemple : une menace est un cybercriminel ayant l'intention de voler des données personnelles. Une vulnérabilité est une application web qui accepte des mots de passe courts et courants sans vérification renforcée. Le risque résulte de la probabilité que le criminel découvre cette vulnérabilité et de la gravité du vol de données pour l'entreprise, par exemple une amende de 2 millions d'euros et une atteinte à la réputation.
