# Atelier : Simuler une tâche planifiée simple

**Rappel théorique** Une tâche planifiée (ou « scheduled task ») est un programme ou un script exécuté automatiquement à intervalles réguliers ou à un moment précis, sans intervention humaine. Sous Linux, cela correspond typiquement à un job cron ; sous Windows, au Planificateur de tâches. En Python, on peut simuler ce comportement directement dans le code en combinant des boucles, la gestion du temps (module `time`) et les arguments en ligne de commande (module `sys` ou `argparse`). Le module `time` fournit notamment `time.sleep(n)` qui suspend l'exécution du script pendant `n` secondes, et `time.strftime()` pour formater l'heure courante. Le module `datetime` complète cela avec une manipulation plus riche des dates et heures. Ces outils sont fondamentaux pour tout script d'automatisation en cybersécurité : collecte périodique de logs, scan réseau répété, surveillance d'un service, etc. Erreurs fréquentes à éviter : oublier de gérer l'interruption clavier (`KeyboardInterrupt`) dans une boucle infinie, négliger l'affichage d'un horodatage lisible dans les logs, ou ne pas valider les arguments passés en ligne de commande avant de les utiliser. Mini-exemple : `import time; [print('tick') or time.sleep(1) for _ in range(3)]` exécute trois itérations espacées d'une seconde. C'est le squelette minimal d'une tâche planifiée simulée en Python. --- **Énoncé de l'atelier** Dans cet atelier, vous allez créer un script Python nommé `task_scheduler.py` qui simule une tâche planifiée de surveillance. Concrètement, le script devra effectuer une action répétée (vérification fictive d'un port ou d'un service) à intervalles réguliers, en affichant un log horodaté à chaque itération, et s'arrêter proprement après...
