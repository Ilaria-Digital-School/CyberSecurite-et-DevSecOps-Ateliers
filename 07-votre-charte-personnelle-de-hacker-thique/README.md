# Votre charte personnelle de hacker éthique

Rappel : ce qui sépare un test d'une attaque Un hacker éthique utilise les mêmes techniques qu'un attaquant. Ce qui l'en distingue, c'est l'autorisation. Sans accord écrit du propriétaire, un test devient une intrusion, quelle que soit votre intention. Le périmètre fixe ce que vous avez le droit de toucher. Les règles d'engagement fixent la manière de le faire : horaires, techniques interdites, contact d'urgence. Retenez cette chaîne : propriétaire, autorisation écrite, périmètre, règles d'engagement. Si un seul maillon manque, vous ne lancez rien. Dans votre laboratoire, vous êtes propriétaire des machines, mais l'isolement réseau reste indispensable. Une machine virtuelle mal configurée peut atteindre votre box ou d'autres appareils de votre réseau domestique. Voici les erreurs fréquentes. Croire qu'une bonne intention protège. Confondre « accessible publiquement » et « autorisé ». Penser qu'un accord oral suffit. Écrire des règles vagues, comme « je serai responsable », que personne ne peut vérifier. Prenons un mini-exemple. Votre laboratoire compte 3 machines virtuelles sur un réseau interne sans accès à Internet : 1 machine d'attaque et 2 cibles. Un scan de la plage d'adresses fait apparaître 4 hôtes au lieu de 3. Le quatrième ne figure pas dans votre inventaire, il est donc hors périmètre. Vous arrêtez le scan, vous notez l'heure et vous vérifiez votre configuration avant toute autre action. Une charte sert précisément à rendre ce réflexe automatique.
