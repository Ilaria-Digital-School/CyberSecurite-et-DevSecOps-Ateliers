# Atelier : lire un log et compter les lignes ERROR

## Rappel théorique En Python, lire un fichier texte repose sur la fonction intégrée `open()`. Elle retourne un objet fichier que l'on peut parcourir ligne par ligne. La syntaxe recommandée utilise le gestionnaire de contexte `with` : `with open('fichier.txt', 'r') as f:`. Ce mécanisme garantit la fermeture automatique du fichier, même en cas d'erreur — une bonne pratique à adopter systématiquement. Une fois le fichier ouvert, on peut lire toutes les lignes d'un coup avec `f.readlines()` (retourne une liste de chaînes), ou itérer directement sur l'objet fichier ligne par ligne (plus économe en mémoire). Pour détecter si une ligne contient un mot-clé comme `ERROR`, on utilise l'opérateur `in` : `if 'ERROR' in ligne`. Attention à la casse : `'error'` et `'ERROR'` sont différents en Python — pensez à normaliser avec `.upper()` ou `.lower()` si besoin. Erreurs fréquentes des débutants : oublier de fermer le fichier sans `with`, confondre `read()` (tout le contenu en une chaîne) et `readlines()` (liste de lignes), ou ne pas gérer le cas où le fichier n'existe pas (ce qui lève une `FileNotFoundError`). Mini-exemple : `count = sum(1 for line in open('app.log') if 'ERROR' in line)` — lisible, mais sans gestion d'erreur ni fermeture explicite.
