# Hacker Éthique & Cyberdéfense

Devenir spécialiste de la cybersécurité, de zéro jusqu'au test d'intrusion professionnel : comprendre les systèmes et les réseaux, attaquer de façon éthique sur un périmètre autorisé, défendre, enquêter et sécuriser le développement. Compétences : Maîtriser les bases mathématiques de l'informatique et de la cryptographie ; Comprendre l'architecture des ordinateurs et des systèmes d'exploitation, administrer Linux ; Concevoir et analyser un réseau ; Programmer en Python et optimiser des algorithmes ; Sécuriser un système d'information ; Concevoir et interroger une base de données ; Utiliser l'intelligence artificielle en attaque et en défense ; Tester la sécurité d'applications web et mobiles ; Réaliser un test d'intrusion complet et son rapport ; Mener une investigation numérique ; Analyser un logiciel malveillant ; Développer de façon sécurisée ; Intégrer la sécurité dans l'intégration et le déploiement continus ; Analyser les risques et auditer la sécurité d'une organisation. Les ateliers se font dans votre laboratoire isolé, sur des cibles et des échantillons d'entraînement que vous installez vous-même ; aucun système réel n'est touché, et les données nécessaires sont fournies.

[Voir l'atelier complet](https://www.ilaria-academy.com/nextjob/appsec-cybersecurity-hacker/fr/)
