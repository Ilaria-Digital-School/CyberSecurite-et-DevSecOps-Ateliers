# Ouvrir votre carnet de laboratoire et y consigner votre installation

Rappel théorique : L'importance de la traçabilité en laboratoire de cybersécurité Un carnet de laboratoire est un document rigoureux qui documente chaque manipulation, configuration et observation réalisée dans un environnement de test. Dans le métier de la cybersécurité, cette pratique est fondamentale. Elle permet de recréer un scénario, d'analyser les effets d'une attaque ou d'une défense, et de fournir un historique vérifiable pour un rapport professionnel. La mentalité principale est celle du scientifique ou du médecin légiste numérique : vous ne travaillez pas de mémoire. L'erreur la plus fréquente est de sauter cette étape par impatience ou de tenir des notes désorganisées, ce qui rend impossible la reproduction d'une configuration spécifique. Un autre piège est de ne pas y consigner les erreurs, alors qu'elles sont souvent des indicateurs précieux. Un mini-exemple : après l'installation d'une machine virtuelle Kali Linux, vous noteriez non seulement la version du système d'exploitation (par exemple Kali Linux 2024.2), mais aussi la commande exacte `uname -a` et son résultat, l'adresse IP attribuée par le logiciel de virtualisation, et les versions des outils critiques comme Nmap. Sans ces informations précises, il serait impossible de savoir si une vulnérabilité trouvée est due à la version d'un outil ou à une configuration réseau incorrecte.
