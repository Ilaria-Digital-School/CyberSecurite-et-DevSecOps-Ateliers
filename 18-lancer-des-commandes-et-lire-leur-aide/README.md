# Lancer des commandes et lire leur aide

Rappels essentiels avant la pratique L'une des compétences fondamentales pour travailler avec Linux, et plus largement dans le domaine de la cybersécurité, est la maîtrise du terminal et de ses commandes. La ligne de commande offre un contrôle précis et automatisable sur le système, sans l'intermédiaire d'une interface graphique. Pour avancer efficacement, vous devez adopter le bon modèle mental : le terminal est un dialogue avec le système, où chaque commande est une instruction que le shell interprète et exécute. Les commandes sont structurées autour d'un nom de programme, suivi d'options et d'arguments. Le nom de la commande (comme `ls` ou `cd`) indique l'action à réaliser. Les options, généralement précédées d'un tiret (`-`) ou d'un double tiret (`--`), modifient le comportement de la commande. Les arguments précisent sur quoi l'action doit porter, comme un nom de fichier ou un répertoire. Une erreur fréquente consiste à confondre options et arguments ou à mal orthographier le nom d'une commande. Lorsque vous ne connaissez pas ou oubliez la syntaxe d'une commande, la première ressource est son système d'aide intégré. Presque toutes les commandes acceptent les options `-h`, `--help`, ou peuvent être consultées via la commande `man` (manuel). Savoir lire cette aide est aussi important que savoir exécuter la commande. Une autre erreur récurrente est de ne pas lire les messages d'erreur retournés par le terminal, qui contiennent souvent l'indice pour corriger le problème. Prenons un mini-exemple concret.
