# Atelier : créer utils.py et l'importer

**Rappel théorique** En Python, un module est simplement un fichier .py contenant des fonctions, des classes ou des variables que l'on peut réutiliser dans d'autres scripts. C'est le mécanisme fondamental qui permet d'organiser son code, d'éviter la duplication et de construire des outils réutilisables — une compétence clé en automatisation sécurité où l'on écrit souvent des scripts similaires (parsing de logs, détection d'anomalies, formatage de rapports). Lorsque vous écrivez `import utils` dans un script, Python cherche un fichier `utils.py` dans le même répertoire (puis dans le PYTHONPATH). Vous accédez ensuite aux fonctions via `utils.ma_fonction()`. Vous pouvez aussi cibler un import précis avec `from utils import ma_fonction`, ce qui importe uniquement ce dont vous avez besoin. La bonne pratique est de protéger le code exécutable d'un module avec le bloc `if __name__ == '__main__':` : ce bloc ne s'exécute que si le fichier est lancé directement, pas lorsqu'il est importé. Erreur fréquente : oublier que `utils.py` doit se trouver dans le même répertoire que le script qui l'importe, ou confondre le nom du module avec celui d'un package pip existant. Mini-exemple : si `utils.py` contient `def saluer(nom): return f'Bonjour {nom}'`, alors dans `main.py` on écrit `import utils` puis `print(utils.saluer('Alice'))` pour afficher `Bonjour Alice`. --- **Énoncé de l'atelier** Dans les ateliers précédents, vous avez construit un script capable de lire un fichier de log, de compter les lignes ERROR et de gérer les exceptions liées aux fichiers manquants.
