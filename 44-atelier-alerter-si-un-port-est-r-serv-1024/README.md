# Atelier : alerter si un port est réservé (<1024)

**Rappel théorique** En réseau, les ports sont des identifiants numériques compris entre 0 et 65535 qui permettent à un système d'exploitation de distinguer les différents services actifs sur une machine. Parmi eux, les ports dits « réservés » ou « bien connus » (well-known ports) correspondent aux numéros allant de 0 à 1023. Ces ports sont attribués par l'IANA (Internet Assigned Numbers Authority) à des services critiques : le port 22 pour SSH, le port 80 pour HTTP, le port 443 pour HTTPS, le port 21 pour FTP, etc. Sur la plupart des systèmes Unix/Linux, seul un utilisateur root (ou un processus disposant de privilèges élevés) peut ouvrir un service sur ces ports. Cette contrainte est une mesure de sécurité fondamentale. En Python, la structure conditionnelle if/else vous permet de prendre une décision selon une valeur.
