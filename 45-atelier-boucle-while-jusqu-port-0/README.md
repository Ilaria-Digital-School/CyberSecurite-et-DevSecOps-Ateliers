# Atelier : Boucle while jusqu’à port 0

**Rappel théorique** La boucle `while` est une structure de contrôle qui répète un bloc d'instructions tant qu'une condition reste vraie. Contrairement à la boucle `for` qui itère sur une séquence connue à l'avance, la boucle `while` est particulièrement adaptée quand on ne sait pas combien d'itérations seront nécessaires — par exemple, attendre une entrée utilisateur valide, scanner des ports jusqu'à une condition d'arrêt, ou traiter des données jusqu'à rencontrer un marqueur de fin. La syntaxe de base est : `while condition:` suivi du bloc indenté. La condition est évaluée avant chaque itération ; si elle est fausse dès le départ, le bloc n'est jamais exécuté. Deux erreurs classiques à éviter : oublier de modifier la variable de condition à l'intérieur de la boucle (ce qui provoque une boucle infinie), et confondre `=` (affectation) avec `==` (comparaison). Mini-exemple : supposons qu'on demande un port à l'utilisateur et qu'on veut continuer tant qu'il ne saisit pas 0. ```python port = int(input("Entrez un port (0 pour quitter) : ")) while port != 0: print(f"Port saisi : {port}") port = int(input("Entrez un port (0 pour quitter) : ")) print("Fin du programme.") ``` Dans un contexte cybersécurité, ce type de boucle est courant dans les scripts de reconnaissance ou de scan interactif, où l'opérateur soumet des cibles une par une jusqu'à décider d'arrêter. --- **Énoncé de l'atelier** Dans cet atelier, vous allez écrire un script Python interactif permettant à un utilisateur de saisir des numéros de ports à analyser, un par un, jusqu'à ce qu'il...
