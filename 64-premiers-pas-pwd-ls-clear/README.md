# Premiers pas : pwd, ls, clear

**Rappel théorique** Avant de plonger dans la pratique, rappelons les bases essentielles. Le terminal Linux est l'interface en ligne de commande (CLI) qui permet d'interagir directement avec le système d'exploitation. Contrairement à une interface graphique, chaque action est exprimée par une commande textuelle, ce qui offre une puissance et une précision indispensables en cybersécurité et DevSecOps. Trois commandes fondamentales balisent vos premiers pas : **pwd** (Print Working Directory) affiche le chemin absolu du répertoire courant — c'est votre boussole dans l'arborescence. **ls** (List) liste le contenu d'un répertoire ; ses options les plus utiles sont `-l` (format détaillé avec permissions, propriétaire, taille, date) et `-a` (affiche les fichiers cachés dont le nom commence par un point). **clear** nettoie simplement l'affichage du terminal pour gagner en lisibilité. Le modèle mental à retenir : le système de fichiers Linux est une arborescence unique dont la racine est `/`. Vous naviguez toujours depuis un emplacement précis (le répertoire courant). `pwd` vous dit où vous êtes, `ls` vous dit ce qu'il y a autour de vous. Erreurs fréquentes : confondre chemin absolu (commence par `/`) et chemin relatif (commence par `.` ou directement par un nom) ; oublier les options de `ls` et rater des fichiers cachés critiques (comme `.bash_history`, `.ssh/`).
