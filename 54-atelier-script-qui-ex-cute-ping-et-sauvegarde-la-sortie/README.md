# Atelier : script qui exécute 'ping' et sauvegarde la sortie

**Rappel théorique** La bibliothèque `subprocess` de Python permet d'exécuter des commandes système directement depuis un script, de capturer leur sortie standard (stdout) et leur sortie d'erreur (stderr), et de récupérer leur code de retour. C'est un outil incontournable en automatisation sécurité : on l'utilise pour piloter des outils comme nmap, ping, curl ou openssl sans quitter l'environnement Python. Le mental model à retenir : `subprocess.run()` lance un processus fils, attend sa fin, et vous retourne un objet `CompletedProcess` contenant `.stdout`, `.stderr` et `.returncode`. Pour capturer la sortie, il faut passer `capture_output=True` (ou `stdout=subprocess.PIPE`) et `text=True` pour obtenir une chaîne de caractères lisible plutôt que des bytes. Erreurs fréquentes à éviter : oublier `text=True` (vous obtenez des bytes au lieu de str), ne pas gérer `FileNotFoundError` si la commande n'existe pas sur le système, ou ignorer le `returncode` (une commande peut 'réussir' à se lancer mais échouer logiquement). Attention aussi aux différences OS : sur Windows, `ping` s'appelle avec `-n` ; sur Linux/macOS, avec `-c`. Mini-exemple : ```python import subprocess resultat = subprocess.run(['ping', '-c', '1', '8.8.8.8'], capture_output=True, text=True) print(resultat.stdout) ``` Ce rappel est le socle de l'atelier qui suit. --- **Énoncé de l'atelier** Dans cet atelier, vous allez concevoir un script Python complet qui automatise l'exécution de la commande `ping` vers une ou plusieurs cibles réseau, capture la sortie de cette commande, gère les erreurs possibles, et sauvegarde les résultats dans un fichier de log horodaté.
