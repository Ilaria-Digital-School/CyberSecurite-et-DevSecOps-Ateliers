# Atelier : déclarer des variables et afficher leur type

**Rappel théorique** En Python, une variable est un espace nommé en mémoire qui stocke une valeur. Contrairement à d'autres langages, Python est à typage dynamique : vous n'avez pas besoin de déclarer le type explicitement, Python l'infère automatiquement à l'assignation. Les types de base sont : int (entier), float (nombre décimal), str (chaîne de caractères), bool (booléen True/False), NoneType (valeur None). La fonction built-in type() retourne le type d'une variable, tandis que isinstance() permet de vérifier si une variable appartient à un type donné. Mental model : imaginez chaque variable comme une étiquette collée sur une boîte. La boîte contient une valeur, et Python détermine automatiquement la nature du contenu. Vous pouvez recoller l'étiquette sur une nouvelle boîte à tout moment (réassignation), ce qui peut changer le type. Erreurs fréquentes : confondre '5' (str) et 5 (int), oublier que True vaut 1 et False vaut 0 en contexte numérique, ne pas distinguer None d'une chaîne vide. Mini-exemple : port = 8080 protocole = 'HTTPS' actif = True print(type(port)) # print(type(protocole)) # print(type(actif)) # --- **Contexte professionnel** Dans le domaine de la cybersécurité et du DevSecOps, vous serez amené à écrire des scripts Python pour automatiser des tâches : scanner des ports, parser des logs, manipuler des données d'API, générer des rapports de vulnérabilités. La maîtrise des types de données est fondamentale : une erreur de type dans un script de pentest peut provoquer un crash silencieux, fausser des résultats ou introduire une faille dans votre propre outil.
