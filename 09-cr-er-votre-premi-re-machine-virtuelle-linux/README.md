# Créer votre première machine virtuelle Linux

Rappel théorique Un hyperviseur est un logiciel qui permet de créer et d'exécuter des machines virtuelles (VM), c'est-à-dire des environnements informatiques isolés qui fonctionnent comme des ordinateurs physiques indépendants. Les machines virtuelles ont leur propre système d'exploitation, leurs applications et leurs ressources allouées, toutes fonctionnant sur le matériel physique de votre ordinateur hôte. Ce concept central est le fondement de tout laboratoire de cybersécurité, car il permet de travailler sur des environnements d'entraînement sans risque pour vos systèmes réels. Le modèle mental clé est de considérer chaque machine virtuelle comme un bien immatériel autonome hébergé dans une «boîte» logicielle. Cette boîte, gérée par l'hyperviseur, tire parti des fonctionnalités de virtualisation du matériel pour répartir efficacement les ressources comme le CPU, la RAM et le stockage. Une erreur fréquente est de surestimer ou de sous-estimer ces allocations. Trop de ressources peuvent ralentir votre hôte, trop peu peuvent rendre la VM inutilisable. Une autre erreur commune consiste à mal configurer le réseau. Le mode NAT, par exemple, permet à la machine virtuelle d'accéder à internet en utilisant l'adresse IP de l'hôte, créant ainsi un réseau privé simple. Une mauvaise configuration réseau est souvent la cause de l'échec de la connectivité internet dans la VM après l'installation. Un mini-exemple concret : pour une distribution Linux légère comme Ubuntu Server, une allocation typique serait de 2 cœurs de processeur virtuel, 4 Go de RAM et un disque dur virtuel de 25 Go. Ces valeurs permettent un fonctionnement fluide sans épuiser les ressources du système...
